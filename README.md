# 打字练习乐园

给 **7 岁半小朋友**用的桌面打字练习软件。Python + tkinter，**零第三方依赖，完全离线**。

教学结构参考 [hellotyping.com](https://hellotyping.com)：成对键位递进 → 练习 / 游戏交替 → 复习。家长侧另外做了两层时长管控（番茄节奏 + 每日额度），退出、关窗、停钟都要管理密码。

| 项 | 说明 |
|---|---|
| 运行环境 | Windows 10 / 11（主平台；源码在装了 tkinter 的 Python 上也能跑） |
| 运行依赖 | **无**。标准库 + tkinter 即可 |
| 打包产物 | 单文件 `打字练习乐园.exe`，约 11 MB，不用装 Python |
| 当前版本 | 1.0.0 |

## 怎么用（家长）

### 下载 / 启动

**推荐：到本仓库 [Releases](../../releases) 下载 `打字练习乐园.exe`**，双击即开。单文件，拷到任何 Windows 电脑都能跑，不用装 Python。

其他方式：

| 文件 | 用途 |
|---|---|
| `打字练习乐园.exe` | **平时用这个**，双击即开（见 Releases） |
| `启动打字练习.bat` | 从源码启动（改了课程内容后用这个，不用重新打包） |
| `调试启动-看报错.bat` | 从源码启动并显示报错 |
| `打包exe.bat` | 改完代码后重新打包 exe |

> **首次打开可能被 Windows 拦一下**（蓝色窗口「Windows 已保护你的电脑」）——这是 PyInstaller 打包程序的常见误报，不是病毒。点「更多信息」→「仍要运行」即可。之后不会再拦。

> 想放桌面：右键 exe → 发送到 → 桌面快捷方式，改名叫「打字练习」。

程序目录会自动生成一个 `data/` 文件夹存配置和练习记录。**换电脑时把 exe 拷过去就行，记录会重新开始。** 要把记录一起带走，把整个文件夹（含 `data/` 和 `我的题库/`）拷过去。

### 第一次打开

会先让你**设一个管理密码**（至少 4 位，输两遍）。

这个密码是给你（家长）用的。孩子不知道密码，就退不出程序、也停不了番茄钟。

**密码不存明文**，用 PBKDF2-HMAC-SHA256（200,000 轮）+ 随机盐，写进 `data/config.json`。

> ⚠️ **忘了密码**：关掉程序 → 删除 `data/config.json` → 重新打开会要求重设密码。
> 练习记录在 `data/progress.json`，不受影响。

### 四个要密码的地方

| 动作 | 需要密码 |
|---|---|
| 点「退出」按钮 | ✅ |
| 按 Alt+F4 / 点窗口关闭按钮 | ✅ |
| 按 Ctrl+Alt+Q | ✅ |
| 停止番茄钟 / 提前结束休息 | ✅ |
| 进「家长」面板 | ✅ |
| 解锁「今日练习时间用完」 | ✅ |

任务管理器强杀进程**没有拦**——按产品定位，孩子还不会这个。

## 两层时长管控

番茄钟管的是**节奏**（学多久、歇多久），每日额度管的是**总量**（今天一共只能用多久）。

两个开关**互相独立**，都在「家长 → 时间管理」里，改动都要密码。可以只要节奏、只要额度、也可以都要。

更完整的需求说明见仓库里的 [`需求-时长管控-v1.md`](需求-时长管控-v1.md)。

### 番茄工作法（管节奏）

顶栏点「开始番茄学习」→ 进入专注倒计时。

- **工作时间 / 休息时间**在「家长 → 时间管理」里设（默认 20 分钟 / 5 分钟，范围 1~120）
- 剩 **60 秒**：顶栏变红 + 响起提醒 + 顶部横幅「把这一组打完就准备休息啦」
- 剩 10 秒：每秒滴答一声
- **时间到 → 全屏锁死**：键盘鼠标全部失效，屏幕显示休息倒计时和护眼提示
- 休息结束自动解锁，回到练习，继续下一个番茄
- 想提前结束休息 / 停止番茄：需要密码
- 家长可以在「时间管理」里**关掉番茄钟**，关掉后孩子点不了

计时口径：**墙钟倒计时**。设了 20 分钟就是 20 分钟，发呆也在走。

### 每日时长限制（管总量）

> ⚠️ **这个功能默认是关的** —— 你得先去「家长 → 时间管理」把「② 每日时长限制」勾上、填个每天上限、点保存。不勾就完全不限时，孩子感觉不到任何变化。

#### 怎么算时间（重要）

**只算「真的在打字」的时间。** 按下按键才计时，停下来超过 15 秒就自动暂停。

所以：发呆、休息、看说明页、挂机 —— **都不扣时间**。

（番茄钟走 20 分钟，额度可能只扣了 12 分钟，这是对的，发呆不该收钱。）

#### 快用完 / 用完了

| 剩余 | 会发生什么 |
|---|---|
| 10 分钟 | 顶栏的「今日剩余」变**橙色** |
| 5 分钟 | 顶部横幅提醒：「把这组打完就收工啦」 |
| 1 分钟 | 响一声提醒 |
| 0 | **锁屏**：整屏变暖色，显示「今天的练习时间用完啦」 |

锁屏后：

- 键盘鼠标全部失效，主界面看不到也点不到
- **关掉程序重开也没用** —— 一启动就会先查今天的用量，超了直接锁
- 屏幕底部有个不显眼的「家长解锁」按钮
- 和番茄休息锁屏叠在一起时：**额度用完优先**（休息几分钟就会过，额度用完是今天到此为止）

#### 家长解锁

点「家长解锁」→ 输管理密码 → 选 **今天还能再用多久**：

```
( ) 30 分钟    ( ) 1 小时
( ) 2 小时     ( ) 5 小时
( ) 今天不限制
 自定义：[___] 分钟
```

- 选「1 小时」= **今天还能再用 1 小时**（不是「在原额度上加 1 小时」）
- 「今天不限制」**只对今天有效**，明天照常恢复每天的上限

家长面板会显示「今日已用 X 分钟 / 加时 Y 次」，方便你看自己放了多松。

#### 什么时候自动回满

**第二天 0 点**（自然日）。程序一直开着也会认，到点自动回满并解锁。

关了额度开关再打开：今天已记录的时间保留，接着算。

|---|---|

| 一、基准键 | f j → d k → s l → a ; → g h，每对键配「练习 + 游戏」，本组结束有通关游戏 |

## 导入单词 / 句子

三种办法，随便挑一种。导入的内容会出现在课程列表最下面的「**六、我导入的题库**」里。

### 办法一：丢文件（最省事，推荐）

1. 打开程序目录下的 **`我的题库`** 文件夹（「家长 → 我的内容 → 打开题库文件夹」也能打开）
2. 丢一个 `.txt` 进去，**一行一条**：

```
apple
banana
orange
```

或者句子：

```
i like my cat
the sun is big
```

3. 程序里「家长 → 我的内容 → **扫描文件夹**」→ 立刻出现在课程里

规则：

- **文件名 = 课程名**（`水果单词.txt` → 课程「水果单词」）
- `#` 开头的行是注释，不参与练习；空行自动跳过
- 行首的序号（`1.` `2、`）会自动去掉
- 改完文件再点一次「扫描文件夹」就同步过来了；**删掉文件不会自动删课程**（星星还在，要在「我的内容」里点删除）
- 启动程序时也会自动扫一遍
- 仓库里自带一份 [`我的题库/示例-英语短句.txt`](我的题库/示例-英语短句.txt)，可直接当模板

### 办法二：粘贴导入

「家长 → 我的内容 → 粘贴导入」→ 把单词或句子直接 Ctrl+V 进去 → 起个名字 → 保存。

### 办法三：从文件导入

「家长 → 我的内容 → 从文件导入」→ 挑电脑上任意一个 txt。内容会先填进编辑框，你可以改拆分方式、遍数，再保存。

### 每条打几遍 —— 可以调

在「我的内容」里选中一个题库 → **编辑** → 「每条打 [3] 遍」。

- 每个题库一个遍数，1~20 遍随便设（单词建议 3~5，句子建议 1~2）
- 想换个顺序练，勾上「打乱顺序」
- **内容太多会自动分课**：一个课最多约 24 行，30 个单词 × 2 遍会自动变成「(1/3) (2/3) (3/3)」三课，每课单独评星
- 长句子会自动按空格折行（在键盘宽度内），不会跑出屏幕

### 只支持这些字符

英文大小写字母、数字、空格，以及 `, . / ; ' - = [ ] \`

> 打出 `?` `!` `:` 需要按 Shift，虚拟键盘画不出来，所以**这类字符默认会被自动去掉**（导入框里那个勾选可以关掉；关掉的话含这些字符的整条会被跳过并告诉你）。
> 中文也打不了，同样处理。

## 练习界面

- **一屏铺开 5~6 行**（跟着当前行滚动），打完一行自动往下走
- 空格显示成一个**浅灰的空槽**（一个空位方块），打过的空槽变浅绿
  - 为什么不给空格配个符号？因为任何符号都可能和键盘上真实的键撞脸（`-` 撞减号、`_` 撞下划线），孩子会把那个符号错记成「空格」。空格就应该是空的。
  - 想让画面更干净：**家长 → 设置 → 空格怎么显示 → 纯空白**
- 打对的字变绿，**当前字黄底高亮**（落在空格上就是一个黄框），打错的字**闪红**（严格模式：必须打对才前进）
- 键盘**按手指分色**，当前该敲的键高亮蓝色
- **键盘下方画了一双手**：手指从手掌伸出来，当前该用哪根手指，那根手指就变蓝加粗、一路指到键上
- 实时显示正确率 / 速度（字/分）/ 打错次数
- 打完一课弹成绩：★☆☆ ~ ★★★（正确率 98% 以上给三星；92% 以上两星，其余一星）

**屏幕自适应**：按屏幕尺寸整体等比缩放，1080p / 2K / 4K 屏上观感一致，不会出现字小得像蚂蚁或挤成一团。

## 数据存在哪、换电脑怎么办

首次运行会在程序目录生成：

```
data/
├── config.json      密码哈希 + 番茄参数 + 每日额度开关 + 全屏/音效/严格模式
├── progress.json    每课星级 / 正确率 / 速度，以及今日额度用量
└── content.json     家长导入的题库缓存（和「我的题库/*.txt」对应）
```

`progress.json` 里额度相关字段：

```json
"usage": {
  "date": "2026-09-13",
  "used_seconds": 1320,
  "quota_seconds": 7200,
  "unlimited": false,
  "grants": 1
}
```

`days` 字段按自然日累计练习秒数和击键数，给以后画「每日练习时长曲线」用，现在界面还没画。

**隐私 / 仓库约定**：`data/config.json`、`data/progress.json`、`data/content.json` 已加入 `.gitignore`，不会被提交。克隆下来的仓库是干净的默认状态，第一次打开会要求重新设密码。

要把一台电脑上的进度迁到另一台：把整个程序目录（至少 `data/` + `我的题库/`）一起拷过去。只拷 exe 会从头开始。

## 从源码运行

环境：

- Windows 10 / 11
- Python 3.8+（需带 tkinter；官方安装包勾选 tcl/tk，Miniconda 一般自带）
- **日常运行不需要 pip 装任何包**

克隆后：

```bash
git clone https://github.com/Rayxtz123/typing-practice-leyuan.git
cd typing-practice-leyuan
python main.py
```

自检（构建界面后立刻退出，不进入主循环，数据写到临时目录，不碰你真实的 `data/`）：

```bash
python main.py --selftest
```

仓库里的 `.bat` 是给本机双击用的，里面写死了本机 Miniconda 路径。别人克隆下来请直接用 `python main.py`，或把 bat 里的 Python 路径改成自己的。

命令行参数：

| 参数 | 作用 |
|---|---|
| （无） | 正常启动 |
| `--selftest` | 自检后退出 |
| `--debug` | 给无控制台的 exe 用：自检并把结果写到 `selftest.log` |

崩溃兜底：无控制台模式下如果挂了，会写 `crash.log` 并弹框，避免「双击没反应、也不知道为什么」。

## 自己重新打包

双击 `打包exe.bat` 就行。它会依次：重画图标 → PyInstaller 打包 → 把 exe 拷到根目录 → 自动跑一遍 exe 自检。

命令行等价写法：

```bash
pip install -r requirements-build.txt
python tools/build_exe.py
```

底层等价于：

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name "打字练习乐园" --icon "<项目根目录的绝对路径>\app.ico" ^
  --distpath dist --workpath build --specpath build main.py
```

两个坑记一下：

- `--icon` 必须给**绝对路径**，否则会被解析到 `--workpath` 下面找不到文件
- `--windowed` 没有控制台，出错看不见 → 所以入口里做了兜底：崩溃会写 `crash.log` 并弹框

排查 exe 问题用：

```bash
打字练习乐园.exe --debug
```

会在同目录生成 `selftest.log`。`build/` 和 `dist/` 是中间产物，可以随时删。

exe **不进 git**（体积约 11 MB，且每台机器自己打包即可）。对外分发走 GitHub Releases。

**加自己的单词/句子**：不用改代码，往 `我的题库/` 丢 txt。

| 文件 | 职责 | 改时长管控时动过 |

| `store.py` | 落盘、密码、额度跨天 | 是 |
| `app.py` | 练习引擎、番茄、额度锁屏 | 是 |
| `dialogs.py` | 家长面板、解锁加时 | 是 |
| `courses.py` | 课程内容 | 说明页补了一句，课表本身没动 |
| `keyboard.py` / `theme.py` | 键盘和外观 | 否 |

## 设计取舍

这些是产品上已经拍板、实现时按这个做的，改之前先想清楚：

| 点 | 选择 | 原因 |
|---|---|---|
| 番茄 vs 每日额度 | 两个独立开关 | 只有总量会没有休息；只有节奏可以打一整天 |
| 额度计时 | 活跃窗口 15 秒，按键驱动 | 发呆、看说明、挂机不该扣时间 |
| 额度默认 | **关** | 装上就被限时、孩子以为软件坏了，是最差的第一印象 |
| 额度用完 | 锁屏，必须密码；重启也拦 | 否则孩子一关一开就能续命 |
| 跨天重置 | 自然日 0 点，运行中也检测 | 不靠重启触发 |
| 系统时间被改 | 不管 | 7 岁半不会，为此加防作弊不值当 |
| 任务管理器杀进程 | 不管 | 同上 |
| 空格的画面 | 空槽，不用符号替代 | 任何符号都可能和真实键撞脸 |
| 中文 / Shift 符号 | 导入时去掉或整条跳过 | 虚拟键盘画不出 Shift 组合键 |
